# SecureShare: Secure Cloud-Based Document Sharing Platform with Access Control and Security Monitoring

SecureShare is a cloud-based document sharing platform designed for academic and enterprise environments to enable secure storage, controlled document distribution, and robust security monitoring with fine-grained access control and end-to-end data confidentiality.

## Technology Stack

- **Frontend:** React + TypeScript
- **Backend:** Python + FastAPI
- **Database:** PostgreSQL
- **Version Control:** Git
